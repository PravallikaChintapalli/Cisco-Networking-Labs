# Cisco-Networking-Labs – Packet Tracer
Cisco Packet Tracer networking labs – VLAN, Trunking, Static Routing, DHCP and ACL.

A collection of hands-on networking labs implemented using Cisco Packet Tracer to practice fundamental networking concepts and configurations.

## Labs Completed

| No. | Lab | Description |
|---|---|---|
| 01 | VLAN Configuration | Created VLAN 10 (Sales) and VLAN 20 (HR) |
| 02 | Trunking | Configured trunk links between switches |
| 03 | Static Routing | Configured communication between two different networks |
| 04 | DHCP Configuration | Configured DHCP pools for automatic IP allocation |
| 05 | ACL Configuration | Configured Extended ACL to control network traffic |

## Technologies Used
- Cisco Packet Tracer
- Cisco IOS CLI
- VLAN
- Trunking
- Static Routing
- DHCP
- Access Control Lists (ACL)

## Learning Outcomes

- Practiced basic network device configuration.
- Understood VLAN segmentation and trunking.
- Implemented static routing between networks.
- Configured DHCP for automatic IP assignment.
- Applied ACL rules to permit and deny network traffic.
- Verified connectivity using ping and IOS commands.
